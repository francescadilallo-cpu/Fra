# Compact Response Style

When reporting progress or results:

1. Prefer concise bullets.
2. Do not restate the full architecture unless asked.
3. Do not paste full files.
4. Do not paste large diffs; summarize them.
5. Include file paths and symbols changed.
6. Include commands run and results.
7. Include only relevant risks or next actions.

## Preferred final format

- Changed:
- Why:
- Checks:
- Docs:
- Notes:

## For investigations

- Found:
- Evidence:
- Likely cause:
- Next smallest step:
